# Эдуард Тихомиров — системный аналитик

Проектирую требования: от интервью с заказчиком до контракта интеграции и программы приёмочных испытаний.

Пришёл в системный анализ потому, что мне интересна точка, где бизнес-задача превращается в понятное разработке решение: разобрать запрос заказчика на сценарии, найти противоречия до того, как их найдёт тестировщик, и описать так, чтобы команда не приходила с вопросами.

**Открыт к предложениям.** Формат работы: Санкт-Петербург, рассматриваю удалёнку и гибрид
